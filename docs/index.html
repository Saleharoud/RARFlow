Engineered for Performance

Everything you need in an archiver.

Designed as a true macOS citizen with native controls, hardware acceleration, and the full feature set of professional archiving tools.

Universal RAR 1.5–7.x Support

Full compatibility with every RAR specification. Handles RAR 4.x, modern RAR 5.x, split volumes (.part01.rar, .r00), and encrypted password archives with ease.

Clean macOS Metadata Stripping

Tired of Windows friends complaining about .DS_Store, __MACOSX, and ._* resource forks? RARFlow automatically strips junk files when creating archives.

AES-256 & Hidden Headers

Military-grade AES-256 encryption. Enable header encryption (-mhe=on) to ensure even filenames and folder structures remain invisible until the password is provided.

Spacebar Quick Look

Press Space on any file in an archive to preview videos, PDF documents, high-res photos, or code without decompressing the entire archive to your disk.

Multi-Volume Volume Splitting

Split large archives into chunks for easy sharing or storage: presets for 100 MB, 700 MB CD, 4 GB FAT32 limit, 4.7 GB DVD, 25 GB Blu-Ray, or custom MB sizes.

Zero External Dependencies

Self-contained arm64 engines bundled directly inside RARFlow.app/Contents/Helpers/. No Homebrew or command-line installs needed. Just drag and drop.

Architecture

Designed purely in Swift 6 for Apple Silicon.

No Electron runtime bloat. No Java dependencies. RARFlow starts in under 0.1s, consumes less than 30MB of RAM, and takes full advantage of multi-threaded compression across all performance cores.

  • Hardware Multithreading: Automatically assigns compression chunks to all CPU cores.
  • Memory-Efficient Streaming: Pipes standard output directly without buffering gigabytes into RAM.
  • Apple Silicon Native: Pure arm64 binaries compiled with strict Swift 6 concurrency safety.
  • Finder Quick Actions: Native macOS Service and LaunchServices integration.
Package.swift 
// Swift 6.0 Strict Concurrency
import PackageDescription

let package = Package(
    name: "RARFlow",
    platforms: [.macOS(.v14)],
    products: [
        .executable(name: "RARFlow", targets: ["RARFlow"])
    ],
    targets: [
        .executableTarget(name: "RARFlow", path: "Sources/RARFlow"),
        .testTarget(name: "RARFlowTests", dependencies: ["RARFlow"])
    ]
)
